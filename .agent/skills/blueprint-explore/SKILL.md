Explore the UniHub Workshop repository without making changes.

## Source Of Truth

- Product and technical specs live in `blueprint/`.
- Read `blueprint/proposal.md`, `blueprint/design.md`, and relevant files in `blueprint/specs/`.
- Use `TASK.MD` only as planning context.
- Real application paths are `server/` and `client/`.

## Workflow

1. Read the relevant Blueprint docs before drawing conclusions.
2. Inspect `server/` and `client/` only as needed to answer the question.
3. Report what exists, what is missing, risks, assumptions, and files to read next.
4. Do not edit files, generate implementation code, or create planning folders.

## Output

Keep the response concrete and project-specific. Prefer file paths, module names, and clear open questions over generic advice.
